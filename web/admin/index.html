访问控制

XFF / IPv6 能力测试

实测上游是否把伪造的 X-Forwarded-For（IPv4 / IPv6）当作独立配额键

测试原理

  1. 分别选取一个随机 IPv4 与随机 IPv6 地址，读取 GET /usage，两者初始应为 remaining=2。
  2. 用该地址作为 X-Forwarded-For 提交一次真实生成。
  3. 再次读取同一地址的 /usage：若 remaining 由 2 变为 1，说明上游确实以该伪造地址作为配额键。
  4. IPv4 与 IPv6 各自独立验证，互不掩盖。
完整测试每个地址族会消耗 1 次上游免费额度（这是唯一能证明配额键归属的方式）；连通性检查不消耗额度。
